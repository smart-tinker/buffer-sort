# Сортировочная

Браузерная головоломка: два заказа, одна входящая лента и буфер на три коробки.

Выбери первую коробку на ленте или коробку из буфера и отправь её в заказ, которому она нужна следующей. Неподходящую коробку с ленты можно отложить. Если буфер заполнился и ни одна коробка не подходит, начни накладную снова. Шесть уровней знакомят с механикой. В «Дневной накладной» очередь меняется по UTC, а лучший результат по числу отправлений в буфер сохраняется в браузере.

Игра не требует регистрации, сервера приложения или внешних ресурсов. Для запуска отдайте содержимое игрового ZIP обычным статическим HTTP-хостом.

## Разработка

Цель и критерии пилота ведём в GitHub Issue, изменения идут через ветку и draft PR. GitHub Actions проверяет решаемость, собирает ZIP и запускает Chromium непосредственно из распакованной сборки. Релизные ZIP и контрольную сумму храним в черновике GitHub Releases. CI не публикует игру, не загружает её на площадки и не использует Actions Artifacts.
